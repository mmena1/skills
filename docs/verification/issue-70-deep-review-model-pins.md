Run `devin models list --format json` in Devin CLI, or the native smoke runs, to confirm them.

## What the repository check proves

Passing `python scripts/check.py` is static configuration validation only. It proves that the role manifest declares exactly the pinned roles, models, efforts, tools, and sandboxes, that each lens runs in exactly its own scout role, and that the generator renders those values into every harness's agent file. It does not prove that any model is available to an account, that a harness accepts an identifier, or that any agent launches. Agent discovery and launch belong to the native smoke runs recorded in `skills/deep-review/runtime-acceptance.md`.
