# Skills may ship native agents that the installer generates and links

`deep-review` needs distinct reviewer roles with their own model, tool, and sandbox limits, and no harness lets a skill directory declare its own subagents: Codex reads `~/.codex/agents/`, Devin reads `~/.config/devin/agents/` (`%APPDATA%\devin\agents\` on Windows), and Claude Code reads `~/.claude/agents/`. We keep each skill's native agent sources inside the owning skill and extend the repository installers with a generic step that links the generated agents into each selected harness's agent directory, with the same recognition, backup, and reconciliation rules as skills. A per-skill `harnesses/roles.toml` manifest plus the skill's reviewer bodies are the only committed source of native-agent behavior. A generic generator, `scripts/generate_agents.py`, deterministically renders every harness's file, with one agent name shared across all harnesses, into `skills/<skill>/harnesses/<harness>/`. We rejected a top-level `harnesses/` tree, which splits one skill's ownership across the repository, and a Claude plugin, which would serve only one of the three harnesses.

The generated harness files are ignored install artifacts, not source. Both installers run the generator for the selected skills that declare roles before they change any destination, then link the output from the same place as before, so linking, junctions, copy fallback, reconciliation, and legacy deep-review migration are unchanged. This makes Python 3.11 or newer an install-time prerequisite whenever a selected skill ships native agents; when no usable Python is found, or generation fails, the installer stops with a clear error before touching any destination rather than installing stale or partial agents. `python scripts/check.py` renders every agent in memory, rejects malformed manifests and missing reviewer bodies, and fails when generated files are tracked by Git or not ignored. This revises the original decision, under which the generated files were committed and the check failed when a committed copy was stale: committing derived output made it look like source, doubled every change, and required the repository to police duplicate representations of the same contract.
